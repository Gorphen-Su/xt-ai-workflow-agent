# xt-sdd-init 项目初始化skill

用于在首次项目上安装以及初始化`xt-sdd`工作流skill的初始化工作

# 流程
1. 判断openspec以及superpowers是否安装好，如果没有则自动安装。
2. openspec init相关工作
3. 项目 init 相关工作
    3.1 判断根目录是否有CLAUDE.md文件，没有则自动创建
    3.2 判断claude.md文件中是否有初始化过增加过工作流规则，状态记录到sdd-project-profile.yaml中，下次调用init 自动判断，如果有执行过该次流程则自动跳过。
    3.3 claude.md 核心记录： 
        ##核心纪律
        1.*＊先读后做＊*：执行任何 OpenSpec 命令前，先读取：
            - openspec / config . yaml （项目约束）
            - openspec / specs /目录下相关域的规范（当前系统行为）
            - openspec / changes /当前活跃的变更（如果存在）
        2.*＊不要猜测需求＊*：如果 spec 中没有明确定义某个行为，问我，不要自行补充，但是你可以建议。
        3.** out - of - scope 是红线＊*: proposal . md 中标注为 out - of - scope 的功能，严禁实现。
    3.4 研读当前项目技术栈、框架，以及文件夹规则等，根据 https://github.com/Fission-AI/OpenSpec/blob/main/openspec/config.yaml 这个内容模式，把当前项目信息补充到当前项目下openspec/openspec.yaml 或者 openspec/config.yaml 文件中， 记录当前是否有初始化过该信息的状态，状态记录到sdd-project-profile.yaml中， 下次调用init 自动判断，如果有执行过该次流程则自动跳过。

4. sdd-project-profile.yaml 中需要记录住是否已经init过项目了， 下次调用init 自动判断，如果有执行过该次流程则自动跳过。
