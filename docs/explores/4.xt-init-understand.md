# 4.xt-init-understand skill
帮助旧项目代码探索，帮助开发者快速理解以及探索项目代码。以供做项目迭代的时候能快速定位到细节。

## 依赖
1. Understand-Anything


## 参考
1. https://mp.weixin.qq.com/s/o-GFCfjX-PKx_d5TOXY25g
2. https://github.com/Lum1104/Understand-Anything/blob/main/READMEs/README.zh-CN.md

## 流程
1. 判断Understand-Anything 是否有安装且能正常使用，如果没有则自动安装，自动判断当前使用的ai 编码平台（默认是claude），并安装。
2. 调用 /understand-domain 完成分析
3. 将分析后生成的内容路径以及查询功能写入Claude.md文件中，方便claude 可以再有需要的时候自动读取里面内容
