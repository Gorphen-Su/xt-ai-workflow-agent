# 4. xt-sdd-apply SKILL.md 修改

修改 xt-sdd-apply skill 的计划文件读取逻辑，支持从 plans/ 目录读取子计划文件。

## 任务清单

- [x] 4.1 修改计划文件读取逻辑 — 从读取单一 plan.md 改为扫描 plans/ 目录、按编号排序读取子计划文件
- [x] 4.2 新增按分组定位子计划文件 — 根据 tasks.md 分组编号和 kebab-case 名称定位对应的 plans/NN-<分组名>.md
- [x] 4.3 新增 plan.md 索引读取 — 从索引文件获取全局执行顺序
- [x] 4.4 新增兼容逻辑 — 检测 plans/ 目录是否存在，不存在则回退到读取单一 plan.md

## 实现步骤

### 任务 4.1：修改计划文件读取逻辑

**修改文件**：`.claude/skills/xt-sdd-apply/SKILL.md`

1. 读取当前 SKILL.md 中读取计划文件的相关步骤
2. 修改读取逻辑：
   - 优先检测 `plans/` 目录是否存在
   - 存在 → 扫描目录下所有 `NN-*.md` 文件，按编号排序
   - 合并所有子计划文件的内容作为执行上下文
3. 替换原来直接读取 `plan.md` 的步骤

### 任务 4.2：新增按分组定位逻辑

**修改文件**：`.claude/skills/xt-sdd-apply/SKILL.md`

1. 在读取计划文件的步骤中，新增定位逻辑：
   - 当执行特定任务时，根据任务编号（如 3.2）确定所属分组（如分组 3）
   - 定位到对应的 `plans/03-<分组名>.md` 文件
   - 从该文件中读取任务的实现步骤
2. 定位规则：
   - 从任务编号 `X.Y` 中提取分组号 `X`
   - 在 plans/ 目录中匹配 `0X-*.md` 或 `X-*.md` 文件

### 任务 4.3：新增索引读取逻辑

**修改文件**：`.claude/skills/xt-sdd-apply/SKILL.md`

1. 在 apply 阶段开始时，新增索引读取步骤：
   - 读取 `plan.md` 索引文件
   - 解析子计划列表和执行顺序
   - 用于展示整体进度和确定下一个要执行的分组
2. 索引中的链接用于在执行时快速定位到对应子计划文件

### 任务 4.4：新增兼容逻辑

**修改文件**：`.claude/skills/xt-sdd-apply/SKILL.md`

1. 新增兼容性检测步骤（在读取计划文件之前执行）：
   - 检查 `plans/` 目录是否存在
   - 存在 → 使用多文件读取模式（任务 4.1-4.3 的逻辑）
   - 不存在 → 回退到读取单一 `plan.md`（原有逻辑）
2. 兼容旧变更目录中只有 plan.md 没有 plans/ 的情况
3. 在日志/输出中提示当前使用的模式：多文件模式 or 单文件兼容模式
